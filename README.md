# Factor-khan

اپ اندروید آفلاین برای مدیریت مشتری و کنترل فاکتور.

## امکانات
- ساخت چند پروفایل مشتری
- ثبت، بازکردن و حذف فاکتور برای هر مشتری
- عکس گرفتن از فاکتور با دوربین
- انتخاب تصویر فاکتور از گوشی
- OCR فارسی + انگلیسی به‌صورت آفلاین با Tesseract 5
- پشتیبانی از ارقام فارسی، عربی و لاتین
- تشخیص جمع کل، مالیات/ارزش افزوده و تخفیف
- محاسبه مجدد ردیف‌های فاکتور و هشدار اختلاف
- امکان اصلاح دستی متن OCR قبل از محاسبه
- امکان واردکردن دستی جمع کل چاپ‌شده
- ذخیره تصویر و اطلاعات فاکتور روی خود گوشی
- حذف جداگانه هر فاکتور یا حذف کامل پروفایل مشتری
- رابط راست‌به‌چپ و فارسی

## حریم خصوصی
OCR و دیتابیس به‌صورت محلی روی دستگاه اجرا می‌شوند و برای خواندن فاکتور نیازی به ارسال تصویر به سرور نیست.

## ساخت APK
GitHub Actions با هر Push روی شاخه main فایل Debug APK را می‌سازد و به‌عنوان Artifact با نام:
`FactorKhan-debug-apk`
قرار می‌دهد.

## OCR
مدل‌های `fas` و `eng` از tessdata_fast در مرحله Build دریافت و داخل APK قرار می‌گیرند.
