# Factor-khan 2.0

اپ اندروید فارسی برای خواندن فاکتور، کنترل محاسبات و نگهداری فاکتورهای هر مشتری.

## نسخه 2.0
- عکس گرفتن از فاکتور یا انتخاب تصویر از گالری
- OCR فارسی + انگلیسی روی خود گوشی
- اجرای چند حالت OCR برای افزایش شانس خواندن عکس‌های واقعی
- تبدیل ارقام فارسی، عربی و لاتین
- استخراج خودکار ردیف‌های کالا از متن OCR
- تشخیص و ویرایش **شرح کالا، تعداد، قیمت واحد و مبلغ ردیف**
- محاسبه خودکار `تعداد × قیمت واحد`
- هشدار اگر مبلغ چاپ‌شده ردیف با محاسبه برنامه اختلاف داشته باشد
- جمع کل همه اقلام
- تشخیص جمع کل، مالیات/ارزش افزوده و تخفیف از متن
- مقایسه جمع محاسبه‌شده با جمع چاپ‌شده و اعلام اختلاف
- امکان اصلاح دستی تمام ردیف‌ها قبل از ذخیره
- افزودن/حذف ردیف دستی
- چند پروفایل مشتری
- ذخیره، بازکردن و حذف فاکتورهای هر مشتری
- حذف کامل مشتری و همه فاکتورهایش
- مهاجرت دیتابیس نسخه 1 بدون پاک‌شدن فاکتورهای قبلی
- RTL و رابط فارسی

## درباره فاکتور دست‌نویس
خواندن دست‌خط از فاکتور چاپی سخت‌تر است و هیچ OCR آفلاین کلاسیک دقت 100٪ ندارد. برنامه برای همین تمام ردیف‌های تشخیص‌داده‌شده را قابل ویرایش نشان می‌دهد و بعد از اصلاح، جمع و خطاها را دوباره محاسبه می‌کند.

## حریم خصوصی
عکس و اطلاعات مشتری داخل گوشی نگهداری می‌شود. OCR اصلی برنامه به‌صورت آفلاین اجرا می‌شود.

## Build
GitHub Actions با Push روی `main` فایل APK را می‌سازد و Artifact با نام `FactorKhan-debug-apk` منتشر می‌کند.
